# cupang-agent — 쿠팡 WING 매니저

쿠팡 WING Open API 연동 상점 관리 프로그램 — Python/Flask.

## 실행
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app.py          # http://<서버IP>:26118
```
`config.json`이 없거나 키가 비어 있으면 **모의 모드**(가짜 상품·경쟁가)로 동작합니다.
실연동: **설정** 화면에서 업체코드·Access Key·Secret Key 입력 → 연결 테스트 → 저장 (config.json, 권한 600).
출고지·반품지 코드는 `config.example.json` 의 `product_defaults` 참고.


## 포터블 버전 (Windows · macOS · Linux)
설치 없이 실행 파일 하나로 쓰는 버전입니다. **GitHub Releases** 에서 내 컴퓨터에 맞는 zip을 받으세요.
사용법은 [PORTABLE.md](PORTABLE.md) 에 있습니다.

- 데이터는 실행 파일 옆 `WING-data/` 폴더에 저장됩니다 (`config.json` · `wing.db` · `uploads/`).
- 기본은 이 컴퓨터에서만 접속(127.0.0.1). `--lan` 을 붙이면 같은 네트워크의 휴대폰에서도 접속할 수 있습니다.
- 새 버전 배포: `version.py` 의 VERSION 을 올리고 `git tag vX.Y.Z && git push origin vX.Y.Z`
  → GitHub Actions(`.github/workflows/portable.yml`)가 5종(windows-x64, macos-arm64, macos-x64, linux-x64, linux-arm64)을
  빌드·실행 확인한 뒤 Releases 에 올립니다.
- 직접 빌드: `pip install pyinstaller && python build_portable.py` (지금 OS용만 만들어집니다).

## 연결 상태 (메뉴바)
메뉴바 아래쪽에서 10초마다 확인합니다 (모바일은 위쪽 막대, 누르면 자세히).
- **프로그램 실행 중 / 응답 없음**: 브라우저가 서버 프로그램에 닿는지. 꺼지거나 네트워크가 끊기면 20초 안에 빨간색.
- **쿠팡 서버 연결됨 / 불안정 / 연결 실패 / 동기화 멈춤 / 연결 안 함(키 없음)**: 인터넷으로 쿠팡 API 서버에 닿는지
  + 실연동이면 마지막 동기화가 성공했는지 (키가 틀리면 인터넷이 되어도 '연결 실패'). 쿠팡 API 서버 IP와 응답 시간 표시.
- **서버 접속 주소**: 이 프로그램이 돌고 있는 서버의 주소(내부망 LAN · Tailscale · 이 컴퓨터). 지금 접속한 주소가 맨 위, 누르면 복사.

## 자동화
- 재고 자동 읽기: 설정한 주기(기본 30초)마다 쿠팡 재고를 읽고 재고 화면이 자동 갱신
- 자동 품절: 재고가 기준(기본 5개) **미만**이면 판매중지, 재입고되면 자동 판매재개 (수동 중지 상품은 제외)
- 주력 상품: 재고 화면에서 ☆ → 대시보드 상단에 카드로 표시

## 구성
| 파일 | 역할 |
|---|---|
| `coupang_client.py` | HMAC 서명 + 상품 조회/생성, 재고·가격 변경 API |
| `services.py` | 주기 동기화, 재고/가격 알림, 자동 가격조정, 등록 페이로드 생성 |
| `store.py` | SQLite (상품 스냅샷, 경쟁가 이력, 규칙, 알림, 등록 로그) |
| `mock_backend.py` | 모의 쿠팡 클라이언트 + 모의 경쟁가 공급자 |
| `app.py` | 화면: 대시보드 / 재고 / 경쟁가 비교 / 상품 등록(단건·CSV) / 설정 |

## 주의
- 쿠팡 Open API에는 **다른 판매자 가격 조회 API가 없습니다.** 경쟁가 공급자(`fetch(item)`)는
  교체 가능하게 분리해 두었고, 현재는 모의 데이터입니다.
- 자동 가격조정은 기본 OFF, 하한가 미만으로는 내리지 않습니다.
- 상품 등록은 기본 임시저장(`requested=false`)입니다.

## 상품 등록
- 대표 이미지: 직접 업로드(JPG/PNG/GIF/WEBP, 10MB) 또는 URL. 업로드 파일은 `uploads/`에 저장되고
  `설정 > 이미지 공개 주소` 기준 URL로 쿠팡에 전달됩니다 (쿠팡 서버가 받아갈 수 있는 인터넷 주소 필요).
- 상세설명: 위지윅 에디터(서식·정렬·목록·링크·이미지 업로드/붙여넣기·HTML 직접 편집). 스크립트·이벤트 속성은 저장 시 제거.
- 💾 임시저장: 필수값 없이 언제든 저장(Ctrl+S). 쿠팡 등록 후에도 같은 임시저장에 남아 계속 수정·저장 가능.
- CSV: `상품 등록 > CSV 템플릿 다운로드` (엑셀용 UTF-8 BOM, 한글 머리글, `[예시]` 행은 업로드 시 무시).
  한 줄 = 옵션 1개 상품. `구매옵션` 칸에 `색상=블랙;수량=1개` 형식으로 필수 구매옵션을 넣고,
  고시정보는 '기타 재화'(없으면 첫 종류) + "상세페이지 참조"로 자동 채움. 배송·반품은 저장한 등록 기본값 사용.

### 단건 등록: 쿠팡 WING 상품등록 화면과 같은 순서·항목
- 13단계: 노출상품명 → 카테고리 → 옵션 → 상품이미지 → 상세설명 → 상품 주요정보 → 검색어 → 검색필터 →
  상품정보제공고시 → 배송 → 반품/교환 → 구비서류 → 판매요청 (쿠팡 판매자 가이드의 등록 순서).
- WING처럼 왼쪽 항목명(필수 ●) · 오른쪽 입력, 선택 항목은 버튼(가능/불가능, 과세/면세, 설정안함/설정함 …).
  옵션은 '단일 상품등록 / 옵션 상품등록', 상세설명은 '이미지 업로드 / 에디터 작성 / HTML 작성' 탭.
- 상품 주요정보는 4개 작은 단계: 브랜드·제조사 → 인증정보 → 판매 조건(병행수입·미성년자 구매·부가세·상품상태) → 구매수량·판매기간.
- 해외구매대행은 WING처럼 배송방법 '구매대행'으로 정해집니다. 모델번호는 옵션 목록에서 옵션별로 입력.
- 하단 버튼: 중간저장(이 프로그램에만) · 미리보기(요청 본문) · 저장하기(쿠팡에 임시저장) · 판매요청(바로 승인요청).
- '다음'은 그 단계의 필수 입력을 확인한 뒤 넘어가고, 위쪽 번호를 누르면 바로 이동합니다.
  번호 표시: 주황 = 지금, ✓ = 다 채움, 주황 테두리 = 빠진 항목 있음, 회색 = 아직 안 봄.
- 미지원: 옵션별 이미지, 판매자 자동가격조정, 카탈로그 매칭 (API·물류 정보가 따로 필요).

### 로켓그로스
- 위쪽 '판매방식'에서 판매자배송 / 로켓그로스를 고릅니다 (둘 다 = 동시 운영, 하나 이상 필수).
- 로켓그로스를 고르면 '로켓그로스' 단계가 생깁니다: 바코드(쿠팡 바코드 자동 생성 / 내 바코드), 물류 입고 정보
  (나중에 WING에서 / 지금: 입고용 상품명·크기 mm·무게 g·소비기한·취급주의), 검수 기준 동의.
- 로켓그로스만 고르면 배송·반품/교환 단계와 옵션의 재고수량 칸이 빠집니다 (쿠팡 창고 입고 수량으로 판매).
- 쿠팡에는 '로켓그로스 상품 생성' 형식(rocketGrowthItemData / marketplaceItemData)으로 보냅니다 (`rocket_growth.py`).
- 사전 준비: WING > 판매자정보 > 추가판매정보 > '로켓그로스 상품 생성 API 이용 및 검수 기준 동의'.

### 단건 등록 항목 (쿠팡 '상품 생성' API 필드 기준, `product_form.py`)
| 섹션 | 내용 |
|---|---|
| 옵션 | 옵션 종류 최대 3개 × 값 → 조합 표(정상가·판매가·재고·판매자코드·바코드, 일괄 적용). 최대 200개 |
| 상품 이미지 / 상세페이지 | 대표 + 추가 이미지 9장, 위지윅 상세설명 |
| 상품 주요정보 | 모델명·상품상태·성인·과세·병행수입·구매대행·인증정보·검색필터·검색태그 |
| 상품정보 제공고시 | 카테고리별 고시 종류·항목 (빈칸 = "상세페이지 참조") |
| 구비서류 | 카테고리가 요구하는 서류 업로드 (PDF·HWP·DOC·DOCX·TXT·PNG·JPG, 5MB) |
| 판매 방식 | 판매기간, 1인 최대구매, 기준출고일, 단위수량, WING 아이디, 승인요청 여부 |
| 배송·출고지 | 배송방법·택배사·배송비 종류, 도서산간·묶음배송, WING 출고지 목록에서 선택 |
| 반품/교환지 | WING 반품지 목록에서 선택 또는 직접 입력(`NO_RETURN_CENTERCODE`), 반품 배송비 |

- 카테고리를 고르면 `카테고리 메타정보 조회` API로 필수 구매옵션(단위 포함)·검색필터·고시정보·구비서류·인증 목록을 불러와
  화면과 서버 검증에 함께 씁니다 (6시간 캐시). 출고지·반품지 목록은 5분 캐시, '↻ 다시 불러오기'로 갱신.
- '다음 상품에도 기본값으로 쓰기'를 체크하면 배송·반품·판매방식 값이 `config.json`의 `register_defaults`에 저장됩니다.

## 카테고리 / 상품명
- 카테고리: 단계별 드롭다운 + 검색. 전체 목록은 `설정 > 쿠팡 카테고리 목록`에서 API로 불러오거나(권장)
  WING '전체 카테고리 엑셀'을 올려서 `categories.json`에 저장. 최하위 단계만 등록 가능.
  키가 없을 때 기본 목록은 쿠팡 개발자 문서에 공개된 25개뿐.
- 노출상품명(구매자에게 표시, 필수) / 등록상품명(판매자 관리용, 비우면 노출상품명 사용).

## 안전장치
- 실연동 + 모의 경쟁가 조합에서는 자동 가격조정·최저가 알림이 꺼짐.
- 동기화 시 쿠팡 목록에 없는 상품(이전 모의 데이터 등)은 DB에서 제거. 한 상품 처리 실패가 전체를 멈추지 않음.

## 텔레그램 알림
`설정 > 텔레그램 알림`: 봇 토큰(@BotFather) → 봇에게 메시지 → 대화 찾기 → 테스트 메시지 → 보낼 알림(재고 / 단가변경) 선택 → 켜기.
- 재고: 재고 부족, 자동 품절, 재입고 판매재개 · 단가변경: 자동 가격조정, 하한가로 조정 중단
- 같은 문장은 6시간에 한 번만 전송, 전송은 백그라운드(동기화 지연 없음). 토큰은 config.json(600)에만 저장, 화면에 비표시.
- 보낼 알림: 재고 · 단가변경 · 내 가격(쿠팡/WING에서 바뀐 판매가) · 경쟁 가격 · 최저가 변동(내 가격과 차이 포함)
- 빈도: 실시간(동기화 1회분을 한 메시지로) / 10분마다 / 1시간마다 — 정각 기준 요약, 같은 상품 변동은 '처음 → 마지막 (n회)' 한 줄
- 시간대: 시작~끝(같으면 하루 종일, 자정 넘김 가능), 시간대 밖 알림은 모아서 시작 시각에 보내기 / 버리기
- 실연동 + 모의 경쟁가 상태에서는 경쟁 가격·최저가 변동 알림을 보내지 않음. 대기 중 알림은 메모리 보관(재시작 시 비워짐)
